📲 Studio installieren

Das Studio kann wie eine App auf deinem Gerät abgelegt werden.

ANDROID / DESKTOPStudio in Chrome oder Edge öffnen und oben auf „Installieren“ klicken. Alternativ Browser-Menü → App installieren.
IPHONE / IPADIn Safari öffnen → Teilen → Zum Home-Bildschirm → Hinzufügen. Falls verfügbar „Als Web-App öffnen“ aktivieren.
WICHTIGInstallation speichert nur die Web-App-Verknüpfung. Du brauchst weiterhin Internet und eine gültige Admin-Anmeldung.
