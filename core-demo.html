Hinweis: CORE erstellt einen spielbaren 3D-Vertical-Slice, kein komplettes AAA-Spiel. Die WebGL-Szene nutzt echte 3D-Geometrie und Perspektive. Das ZIP enthält ein Windows-Buildprojekt; die EXE wird anschließend auf einem Windows-PC erzeugt. Keine fremden Spielwelten oder Marken werden kopiert.
